# Hospitality Booking and Management System

## Final-year project summary

The Hospitality Booking and Management System is a secure web application for
Zambian lodges and hotels. It replaces paper registers and disconnected
spreadsheets with one system for reservations, guests, rooms, payments,
expenses, staff operations, housekeeping, reports and audit records.

## Problem statement

Many small and medium hospitality businesses experience double-bookings,
incomplete guest records, weak revenue tracking, delayed housekeeping updates
and limited accountability. These problems affect customer service and make
management reporting difficult.

## Aim

To design and implement a reliable, role-based hospitality platform that
improves booking accuracy, operational control and financial visibility.

## Objectives

1. Prevent overlapping reservations for the same room.
2. Centralise guest, room, booking and payment information.
3. Support check-in, check-out, housekeeping and front-desk workflows.
4. Produce receipts, invoices and management reports in Zambian Kwacha.
5. Enforce staff permissions and maintain an audit trail.
6. Provide backup, testing and deployment procedures suitable for production.

## Scope

The system supports property setup, staff roles, room types, rooms, guests,
bookings, booking approval, availability, payments, expenses, housekeeping,
front desk, reports, receipts, invoices, security settings and audit logs.
Online payment-gateway settlement and integration with government systems are
possible future extensions.

## Technology

- Next.js and TypeScript for the user interface and server APIs.
- PostgreSQL for reliable relational data storage.
- Prisma ORM for database access and migrations.
- Zod for server-side input validation.
- Docker for consistent deployment.
- GitHub Actions for automated quality checks.

## Expected benefits

The project reduces booking conflicts, improves guest service, strengthens
financial accountability, provides timely occupancy information and supports
evidence-based management decisions.
